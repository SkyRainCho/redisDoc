# Redis 6.2 发布说明

## Redis 6.2 版本介绍

这是在新的项目治理模式下由核心团队管理的第一个重要 Redis 版本。

Redis 6.2 包含了许多新命令和改进，但没有大型功能。
它主要使 Redis 更加完整，并解决了许多用户经常或长期要求的问题。

这些变更中有许多不适合包含在 6.0.x 版本中，原因如下：

1. 它们不向后兼容，这在新增或扩展命令时总是如此（这些命令无法复制到旧版本的从节点）。
2. 它们需要更长的候选版本测试周期。


以下是与 6.0.9 版本相比，此版本的全面变更列表。
每项变更都包含了添加它的 PR 编号，
因此你可以在 https://github.com/redis/redis/pull/ 获取更多详细信息。

### 新命令/参数

- 添加 SMISMEMBER 命令，用于检查多个成员 (#7615)
- 添加 ZMSCORE 命令，返回一个分数数组 (#7593)
- 添加 LMOVE 和 BLMOVE 命令，可以任意弹出和推入元素 (#6929)
- 添加 RESET 命令，用于重置客户端连接状态 (#7982)
- 添加 COPY 命令，用于复制键 (#7953)
- 添加 ZDIFF 和 ZDIFFSTORE 命令 (#7961)
- 添加 ZINTER 和 ZUNION 命令 (#7794)
- 添加 GEOSEARCH/GEOSEARCHSTORE 命令，用于边界框空间查询 (#8094)
- 为 SET 命令添加 GET 参数，实现更强大的 GETSET 功能 (#7852)
- 为 XPENDING 添加独占范围查询 (#8130)
- 为 X[REV]RANGE 添加独占范围查询 (#8072)
- 为 ZADD 添加 GT 和 LT 选项，用于条件分数更新 (#7818)
- 添加 CLIENT INFO 和 CLIENT LIST 命令，用于特定 ID (#8113)
- 为 XPENDING 命令添加 IDLE 参数 (#7972)
- 在 CLIENT LIST 中添加本地地址，以及 CLIENT KILL 过滤器 (#7913)
- 为 XADD 命令添加 NOMKSTREAM 选项 (#7910)
- 为 Sentinel 添加命令内省功能 (#7940)
- 添加 SENTINEL MYID 子命令 (#7858)

### 新特性

- 转储负载清理：防止损坏的负载导致崩溃 (#7807) 
有启用完整 O(N) 验证的标志（默认禁用）。
- 为 Pub/Sub 频道添加 ACL 模式 (#7993)
- 为 Sentinel 模式支持 ACL (#7888)
- 支持同时从标准输入和文件获取配置 (#7893) 
让你可以避免在磁盘上存储机密信息。
