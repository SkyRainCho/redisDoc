# Redis 6.0 发布说明

升级紧急程度:

- **LOW**-低: 除非有你想使用的新功能,否则无需升级。 
- **MODERATE**-中等: 计划升级服务器,但不紧急。 
- **HIGH**-高: 存在可能影响部分用户的关键bug。请升级! 
- **CRITICAL**-严重: 存在影响大多数用户的关键bug。请尽快升级! 
- **SECURITY**-安全: 此版本包含安全修复。

## Redis 6.0 介绍

Redis 6 在多个关键领域改进了 Redis，是该项目历史上最大的 Redis 版本之一。以下列出了此版本中最重要的特性：

1. 模块系统现在有许多新的 API，允许模块作者实现以前无法实现的功能。现在可以在 RDB 文件中存储任意的模块私有数据，可以挂钩不同的服务器事件，捕获和重写命令执行，在键上阻塞客户端等等。

2. Redis 的主动过期循环被重写，可以更快地驱逐已过期的键。现在这个过程的力度是可调的。

3. Redis 现在支持所有通道上的 SSL。

4. 支持 ACL，你可以定义只能运行某些命令和/或只能访问某些键模式的用户。

5. Redis 现在支持一个名为 RESP3 的新协议，它返回更具语义的回复：使用此协议的新客户端可以直接从回复中理解应该向调用程序返回什么类型。

6. 服务器端支持客户端缓存键值。这个特性仍然是实验性的，在接下来的候选版本中会有更多变化，但你已经可以测试它并在这里阅读相关信息：
https://redis.io/topics/client-side-caching

7. Redis 现在可以选择使用线程来处理 I/O，当无法使用管道时，允许单个实例每秒处理 2 倍的操作。

8. 现在即使在从节点上也支持无盘复制：在用户可以配置的某些条件下，从节点现在能够在第一次同步时直接从套接字将 RDB 加载到内存中。

9. Redis-benchmark 现在支持 Redis 集群模式。

10. SRANDMEMBER 和类似命令现在有更好的分布。

11. Redis-cli 有所改进。

12. 重写了 Systemd 支持。

13. 发布了一个 Redis 集群代理，可在此处获取：
https://github.com/artix75/redis-cluster-proxy

14. 为 Redis 发布了一个 Disque 模块，可在此处获取：
https://github.com/antirez/disque-module
